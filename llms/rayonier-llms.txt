# Rayonier

> Rayonier (NYSE: RYN) is a timberland real estate investment trust owning about 2 million acres in the US South and Pacific Northwest. It publishes no developer program, but it runs a self-hosted ArcGIS Enterprise 11.5 instance at gis.rayonier.com whose Public and Hosted folders (45 services, 102 layers) answer anonymously — fee ownership, hunting lease units, bee-lease sites, land-sale tracts, forest stand inventory and wildfire overlays. This file was generated by API Evangelist from that surface on 2026-09-17; Rayonier serves no llms.txt of its own (404).

## API

- [ArcGIS REST services directory](https://gis.rayonier.com/arcgis/rest/services): HTML by default; append ?f=json for machine-readable output. Folders: Public (29 services), Hosted (16 services), Utilities (token required).
- [Server info](https://gis.rayonier.com/arcgis/rest/info?f=json): ArcGIS Enterprise 11.5; token security enabled but not required on Public/Hosted.
- [Fee ownership layer](https://gis.rayonier.com/arcgis/rest/services/Public/Rayonier_FEE_Ownership_Public/FeatureServer/0?f=json): 6,216 polygons; query with /query?where=1%3D1&f=geojson (maxRecordCount 5000).
- [Hunting lease units](https://gis.rayonier.com/arcgis/rest/services/Public/Hunting_RLU_Permits_Salesforce/MapServer?f=json): 13 layers feeding rayonierhunting.com.
- [Bee lease sites](https://gis.rayonier.com/arcgis/rest/services/Public/BeeLease_WebSite/MapServer?f=json): Available / Currently Unavailable, rebuilt nightly, consumed by rayonierbeekeeping.com.
- [SOAP contract (WSDL)](https://gis.rayonier.com/arcgis/services/Public/Rayonier_FEE_Ownership_Public/MapServer?wsdl): 55 MapServer operations, WSDL 1.1.

## Conventions

- No credential on Public/ and Hosted/; the Utilities folder returns {"error":{"code":499,"message":"Token Required"}}. No self-signup for tokens.
- Errors are delivered inside HTTP 200 as {"error":{"code","message","details"}} — parse the body.
- Pagination: resultOffset / resultRecordCount; maxRecordCount is per layer (2000 typical, 5000 on fee ownership).
- Output: f=json (esriJSON), f=geojson, f=pbf on FeatureServer layers. Default spatial reference is Web Mercator (3857); pass outSR=4326 for WGS 84.
- No OGC WMS/WFS (400), no OpenAPI, no rate-limit headers, no status page, no versioning policy.
- Nine services advertise editing capabilities; treat the surface as read-only and do not attempt writes.
